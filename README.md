To-Do List Application 📝

About the Project

The To-Do List is a simple command-line application developed using Python as part of the CodSoft Python Programming Internship.

It helps users manage their daily tasks by allowing them to add, view, and remove tasks through a menu-driven interface.

Features

- Add Task: Add new tasks to the list.
- View Tasks: Display all added tasks with numbers.
- Remove Task: Remove a task by entering its number.
- Input Validation: Handles invalid menu choices and task numbers.
- Empty Task Check: Prevents adding an empty task.
- Exit Option: Exit the application safely.

Technologies Used

- Python 3
- Visual Studio Code

How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

python todo_list.py

How to Use

1. Run the program.
2. Select an option from the menu:
   - "1" — Add Task
   - "2" — View Tasks
   - "3" — Remove Task
   - "4" — Exit
3. Follow the instructions displayed in the terminal.

Example

===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Remove Task
4. Exit

Enter your choice (1-4): 1
Enter a new task: Complete assignment
Task added successfully!

Important Note

Tasks are stored temporarily in memory. They will be lost when the program exits because permanent file or database storage is not implemented.
